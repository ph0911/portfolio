## Vom Portfolio zum Arbeitsraum

V2 behandelt diese Website als laufendes Produkt. Projekte bilden weiterhin den
stabilen Überblick, während ein Dev Log kleine Fortschritte, Entscheidungen und
Learnings zeitnah sichtbar macht. Ein kompakter Resume-Bereich bleibt als
Bewerbungs-Backbone erhalten.

## Publizieren ohne Codeeditor

Neue Log-Einträge beginnen in einem strukturierten GitHub Issue, das auch mobil
ausgefüllt werden kann. Erst ein separates Publish-Label gibt den Inhalt bewusst
frei. Die Pipeline prüft die Eingaben, erzeugt eine validierte MDX-Datei und
stößt damit das bestehende Deployment an.

So bleiben Inhalte versioniert und die Website statisch schnell, ohne dass jede
kleine Aktualisierung einen lokalen Editor oder ein zusätzliches,
kostenpflichtiges CMS benötigt.

## Bewusste Grenzen

Die Pipeline akzeptiert nur klar definierte Textfelder und öffentliche Links.
Sie veröffentlicht keine Anhänge und hält Entwurf und Freigabe getrennt. Das
macht den kurzen Weg in den Log bequem, ohne die Kontrolle über öffentliche
Inhalte abzugeben.
